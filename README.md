# ProcuraLogic

Website for ProcuraLogic — manual contract review and advisory.

**Live site:** https://procura-logic.com

## Files
- `index.html` — the site (single-file, Tailwind CDN + Iconify)
- `contract-guide.pdf` — free downloadable guide
- `CNAME` — custom domain config for GitHub Pages

## Deploy
1. Push to `main` branch
2. Repo Settings → Pages → Source: `main` / root
3. Custom domain: `procura-logic.com` → Save → Enforce HTTPS
4. At domain registrar, set DNS A records to `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` and CNAME `www` → `procuralogic-rgb.github.io`
